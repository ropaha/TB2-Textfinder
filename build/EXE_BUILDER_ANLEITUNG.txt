EXE-Builder fuer Windows

ZIP komplett entpacken. Build_EXE.bat baut alle drei Programme.
Einzelne Programme: python build/build.py textfinder --local (alternativ negativtester oder textcounter).
Python 3.10+ und Internet fuer die Build-Abhaengigkeiten erforderlich.
Die Batch-Dateien verwenden build/build.py und eine lokale .venv.
Alternativ: python build/build.py all --local
Vorschau: python build/build.py all --dry-run
Die fertigen EXEs liegen in dist und brauchen kein Python.
